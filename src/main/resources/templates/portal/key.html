The B2B token request is signed with your private key (SHA256withRSA over X-CLIENT-KEY|X-TIMESTAMP). The simulator verifies it with the public key registered here. Registering a key replaces the current one.

Option 1: generate in the simulator

        
Creates an RSA-2048 pair, registers the public key and downloads the private key as
            private.pem (PKCS#8). The private key is not stored: if the download is lost, generate again.

        

            
        

    


    

        
Option 2: generate locally and upload the public key

        
openssl genpkey -algorithm RSA -pkeyopt rsa_keygen_bits:2048 -out private.pem
openssl pkey -in private.pem -pubout -out public.pem

        
genpkey writes PKCS#8 (BEGIN PRIVATE KEY), which Java's
            PKCS8EncodedKeySpec reads directly. openssl genrsa on OpenSSL 1.1 writes PKCS#1
            (BEGIN RSA PRIVATE KEY); convert it with
            openssl pkcs8 -topk8 -nocrypt -in old.pem -out private.pem.

# Security

This is a test tool: it simulates a bank's SNAP interface for local
development and must not hold real credentials, real customer data or be
exposed as a production service. Production hardening (lockout, rate
limiting, field encryption, audit log) is deliberately absent; see
`docs/engineering-standard.md`.

Report vulnerabilities privately through GitHub Security Advisories
(Security tab → Report a vulnerability) on
https://github.com/artivisi/snap-provider-simulator. Do not open public issues
for them.
